# SolazeTech portfolio

A responsive static portfolio using `index.html`, `style.css`, and `script.js`.

## Preview

Open `index.html` in a browser, or serve this folder with `python -m http.server 8000` and visit `http://localhost:8000`.

## Structure

- `assets/portraits/` contains the selected profile portrait.
- `assets/projects/` contains the workflow and output screenshots used on the page.
- `index.html` contains the semantic page content and metadata.
- `style.css` contains the responsive visual system and light/dark themes.
- `script.js` handles the mobile menu, theme preference, and current year.
- `robots.txt` and `sitemap.xml` help search crawlers discover the published portfolio.

The project screenshots link directly to their full-size originals. Their captions describe the evidence visible in each capture; execution and deployment status are left unverified where the images cannot establish them.

## Publish

Keep the root `index.html`, `style.css`, `script.js`, and `assets/` together when publishing to GitHub Pages. Verify the published links and images after pushing to the repository serving the portfolio URL.

The canonical portfolio URL and sitemap currently target `https://solaze01.github.io/solazetech/`. If the repository or GitHub Pages URL changes, update the canonical, Open Graph, social image, structured data, `robots.txt`, and `sitemap.xml` URLs together.

The contact link uses `mailto:` and does not submit to a backend. The Shopify order operations demo is not listed as completed.
